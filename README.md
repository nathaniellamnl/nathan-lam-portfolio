# Nathan Lam — Portfolio

Personal portfolio site built with React + Vite, deployed to GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

This builds the site and pushes the `dist` folder to the `gh-pages` branch.

Site URL (after Pages is enabled):

`https://<your-github-username>.github.io/nathan-lam-portfolio/`
